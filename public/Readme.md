Всё содержимое public/ при сборке просто копируется в корень папки dist/ в неизменном виде (без сжатия и без добавления хешей к именам). Сюда обычно кладут:
• Фавиконки и манифесты: favicon.ico, favicon.svg, apple-touch-icon.png, site.webmanifest (браузеры и поисковики ищут их строго по фиксированным именам).
• Картинки для соцсетей (Open Graph): например, og-image.jpg для тега meta(property="og:image"), где нужна постоянная прямая ссылка.
• Служебные файлы сайта: robots.txt, sitemap.xml, CNAME.
• Файлы для динамической подгрузки через JS: например, моковые .json файлы или картинки, пути к которым собираются в JavaScript динамически через шаблонные строки.
Важно: в коде (в Pug или CSS) к файлам из public/ обращаются от корня сайта — без слова public в пути (например, href="/favicon.ico", а не "/public/favicon.ico").
